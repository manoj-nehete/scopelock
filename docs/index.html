ScopeLock v0.1.0

Free, local-first scope governance and evidence tracking for coding agents.

ScopeLock keeps AI coding agents (Claude Code, OpenAI Codex, Antigravity) aligned with agreed requirements through phase-wise milestones, verifiable checks, and a unified journal.

User Guide & Quickstart

Step-by-step instructions from installation to running your first multi-agent project in 3 minutes.

Agent Integrations

Setup guides, configuration details, and compatibility matrix for Antigravity, Claude Code, and Codex.

System Specification

Data models, transactional consistency rules, exit gates, and MCP tool definitions.

Build Requirements

Complete traceability matrix linking features, phases, and acceptance criteria.

Quick Installation

git clone https://github.com/manoj-nehete/scopelock.git
cd scopelock
npm ci
npm run build
npm link

# Initialize in any project
cd /path/to/my-project
scopelock init "My Project"
scopelock dashboard
